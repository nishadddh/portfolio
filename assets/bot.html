Pet Application Setup Guide

Welcome to the Pet Application! Follow these steps to set up and use the application on your Windows computer.

Prerequisites
  • Python 3.10 or higher. Download from here.
  • Required Python packages:
    • psutil
    • PyQt5

Installation Steps

  1. Install Python 3.10 or higher if it is not already installed.
  2. Download the Pet Application files and extract them to a desired location.
  3. Open a terminal or command prompt and navigate to the directory where you extracted the files.
  4. Install the required Python packages by running the following commands: 
    pip install psutil PyQt5

Running the Pet Application

  1. Create a batch file to run the application: 
    @echo off
start /B pythonw "D:\path\to\your\Mypet.py"
    Replace D:\path\to\your\Mypet.py with the actual path to your Mypet.py file.
  2. Double-click the batch file to start the pet application.

Setting Up the Application to Run on Startup

  1. Press Win + R to open the Run dialog.
  2. Type shell:startup and press Enter. This will open the Startup folder.
  3. Copy the batch file you created and paste it into the Startup folder.

Troubleshooting

If you encounter any issues, ensure that:

  • The paths in your batch file are correct.
  • Python and the required packages are installed correctly.

If problems persist, consult the Python documentation or seek help from online forums and communities.
